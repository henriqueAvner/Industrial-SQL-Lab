# Roteiro de exercícios por dia

Os 100 exercícios estão distribuídos por assunto e dificuldade em 20 dias de estudo. Os dias representam sessões sugeridas, sem datas ou duração obrigatória.

Leia primeiro o README do dia e resolva os arquivos na ordem apresentada. Todos usam a base original de julho a setembro de 2026; não altere os dados. Os enunciados originais e o arquivo minhas_respostas.sql foram preservados.
